# Metabolic Click-to-Kill (MCK) — computational Phase 0

Code, data, and figures for the MSc thesis *"Metabolic Click-to-Kill: Computational Design of a Spatially Gated Artificial-Antigen NK-Engager Platform for Solid Tumours"*. MCK is a proposed antigen-independent NK-cell immunotherapy; this repository holds the computational feasibility assessment and the design work behind it. No wet-lab data are included — the project is explicitly a computational Phase 0.

## What is here
```
code/        analysis models (core + round9_laptop_pack/ heavier optional jobs)
data/        digitised literature values + GTEx / DepMap inputs used by the gate engine
figures/     figure images + the schematic generator (mck_schematics.py)
references.bib   bibliography
environment.yml / requirements.txt   environments
```
The thesis document itself is provided separately as a PDF; this repository is the
computational supplement. Numerical result files are regenerated by running the
scripts below (they are not committed, so the repository stays small and the
outputs stay deterministic under the fixed seeds).

## Reproduce the numbers
```bash
conda env create -f environment.yml && conda activate mck     # or: pip install -r requirements.txt
cd code
python sweep_mck.py                    # therapeutic-index sweep (worst-case floor 1.37)
python round9_TI_primary.py            # primary TI median 2.16 / 19.8% clearing 3
python joint_feasibility.py            # reach 96.6% and reach-and-selective compound feasibility
python synapse_geometry.py             # reach-vs-kill geometry: a fixed tether cannot do both
python round9_A1_permeability.py       # third-gate uptake gating (RDKit)
python abm_ch6.py                      # killing ABM (pure-MCK ~0.96x; Niu-calibrated)
python third_gate.py                   # third-gate selectivity multiplication
python round9_laptop_pack/round9_A2_bystander_radius.py
python round9_laptop_pack/round9_S4_mucinase_audit.py
```
All randomness is seeded (default 42), so the numbers are reproducible run to run.
Optional heavy chemistry checks (separate environments; see `code/round9_laptop_pack/README_COMPUTE_PACK.md`): self-immolation energetics (xtb), beta-glucuronidase docking (Vina), and 310 K stability MD (OpenMM).

## Figure → source map
| figure | produced by |
|---|---|
| data plots (calibration, TI distribution, safety map, killing ladder, requirements map, etc.) | the analysis scripts in `code/` |
| third-gate location-gate mechanism; beta-glucuronidase docking pose | `figures/mck_schematics.py` |
| self-immolation free-energy profile | `code/round9_laptop_pack/round9_A1_selfimmol_verdict.py` |
| conceptual schematics (reach geometry, MCK-E triple-bind, synthetic scheme) | vector art, prepared separately |

## Data sources
GTEx (normal-tissue expression) and DepMap (cancer expression) are public; digitised literature values are listed with their sources in `data/`. Third-party datasets and copyrighted publications are cited in the thesis but not redistributed here.
